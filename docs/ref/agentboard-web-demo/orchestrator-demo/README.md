# AgentBoard — demonstração web

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador moderno.

Não é necessário instalar dependências ou iniciar um servidor.

## Conteúdo da demonstração

- Quadro Kanban com tasks e colunas de execução.
- Navegação para tasks, agentes, execuções e configuração.
- Simulação de movimentação de cards, detalhe de task e eventos em tempo real.
- Tema escuro em tons de laranja.

Os dados são demonstrativos e permanecem somente no navegador.
